# ShadowLab Branding Direction

## Product Name

Use the product name consistently:

- `ShadowLab`

Avoid alternate product names unless a workspace subtitle is required, such as `Enterprise Ops`, `Enterprise Intel`, `Security Ops`, `File Analysis`, or `Antivirus & Containment`.

## Product Positioning

ShadowLab should read as:

- a Windows-focused cybersecurity operations platform
- a local detection engineering and incident-response lab
- an operator console for process investigation, file analysis, containment, integrations, casework, and security readiness

Avoid positioning it as only:

- a packet sniffer
- a toy malware lab
- a generic dashboard
- a red-team automation tool

## Visual Direction

Preferred tone:

- precise
- tactical
- modern
- operator-focused
- calm under pressure

Avoid:

- cartoonish cyber imagery
- generic lock-only branding
- loud gradients that hurt dashboard readability
- stock-photo hacker visuals
- decorative effects that make dense security data harder to scan

## Core Colors

- deep navy: `#10151d`
- operational blue: `#1d7df2`
- steel: `#243446`
- alert red: `#d64550`
- success green: `#2f9e67`
- warning amber: `#f4c26b`
